Passwords are never stored here

Each account keeps only a random 16-byte salt and the SHA-256 hash of the password combined with that salt. Even if the database is stolen, the original passwords are not in it.

Create an account Log in

1. Salt

os.urandom(16) produces a fresh random salt for every password.

2. Hash

SHA-256(password + salt) is computed with hashlib.

3. Store

Only the salt and the hash go into the SQLite database.

4. Verify

At login the entered password is re-hashed with the stored salt and compared.
